# E_Wallet — Plantillas de maquetado (Login / Dashboard / Envío / Recarga / Registro)

Contenido:
- 5 páginas HTML en `pages/`
- CSS compartido en `styles/styles.css`
- SVG assets en `assets/` (logo + iconos)

Paleta:
- Base: #131e3a
- Acento: #038cb2
- Highlight: #f39c12

Instrucciones para ver en VS Code (recomendado):
1. Abre la carpeta en VS Code.
2. Instala la extensión "Live Server" (ritwickdey.liveserver).
3. Click derecho en cualquiera de los archivos HTML en `pages/` → Open with Live Server.
4. El navegador abrirá la página; para capturar PNG:
   - Desktop: ajusta la ventana del navegador a 1920×1080 y haz captura de pantalla (o usa DevTools → More tools → Run Command → "Capture full size screenshot").
   - Mobile: abre DevTools (F12) → Toggle device toolbar (Ctrl+Shift+M), selecciona tamaño iPhone 12 / 375×812 y usa "Capture screenshot" para exportar la vista.
